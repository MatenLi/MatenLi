> **Статус:** эта страница описывает формат модулей версии 1, который реализует следующий выпуск.
> Схема ниже — контракт, на который могут опираться авторы модулей.

## Что такое модуль

Модуль — это **ZIP-архив** с двумя видами файлов внутри:

1. `module.json`: описывает модуль. Название, протоколы, которые он добавляет, и настройки, которые ему нужны.
2. Файлы нативных библиотек (`.so`): код, который нужен модулю во время работы, если он вообще нужен.

Установите модуль через **Модули > Импорт (zip)**. Приложение прочитает JSON, проверит его и покажет модуль в списке.

```text
my-module.zip
├── module.json
└── libmymodule.so
```

## Что можно сделать с модулем

| Действие               | Что делает                                              |
| ---------------------- | ------------------------------------------------------- |
| Закрепить              | Держит модуль в начале списка.                          |
| Включить или выключить | Включает или выключает протоколы модуля, не удаляя его. |
| Удалить                | Удаляет модуль и его настройки.                         |
| Обновить               | Проверяет GitHub-релизы модуля на более новую версию.   |
| Настройки              | Открывает пользовательские настройки модуля.            |

## Схема module.json (версия 1)

| Поле                 | Тип            | Обязательно | Значение                                                                                                   |
| -------------------- | -------------- | ----------- | ---------------------------------------------------------------------------------------------------------- |
| `apiVersion`         | число          | да          | Должно быть `1`.                                                                                           |
| `name`               | текст          | да          | Показывается в списке.                                                                                     |
| `version`            | текст          | да          | Семантическая версия, например `1.2.0`. Используется обновлениями.                                         |
| `description`        | текст          | да          | Одно-два предложения.                                                                                      |
| `homepage`           | URL            | нет         | Страница проекта.                                                                                          |
| `updateUrl`          | URL            | нет         | Репозиторий GitHub, например `https://github.com/owner/repo`. Обновления берутся из его последнего релиза. |
| `schemes`            | список текстов | нет         | Начала ссылок, которые модуль обрабатывает на уровне модуля.                                               |
| `helperBinary`       | объект         | нет         | Нативная библиотека для загрузки по платформам. Например `{"android": "libmymodule.so"}`.                  |
| `parallelPing`       | логический     | нет         | Проверять профили модуля одновременно. По умолчанию `false`.                                               |
| `pingWhileConnected` | логический     | нет         | Обновлять задержку при подключении. По умолчанию `true`.                                                   |
| `pingTimeoutSec`     | число          | нет         | Секунд до отказа проверки. По умолчанию `10`.                                                              |
| `handoverMode`       | текст          | нет         | Как модуль передаёт трафик. В версии 1 единственное значение — `signal`.                                   |
| `relayWindowSec`     | число          | нет         | Секунд, которые ретранслятор живёт при передаче. По умолчанию `0`.                                         |
| `protocols`          | список         | нет         | Протоколы, которые добавляет модуль. См. ниже.                                                             |
| `customSettings`     | список         | нет         | Настройки на странице модуля. См. ниже.                                                                    |

### Протоколы

Каждый элемент `protocols` добавляет один протокол в разбор ссылок и в ядро:

| Поле       | Тип            | Значение                                                                                                                  |
| ---------- | -------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `id`       | текст          | Уникальный идентификатор в нижнем регистре, например `stormdns-dns`.                                                      |
| `name`     | текст          | Показывается в редакторе профиля.                                                                                         |
| `core`     | текст          | `sing-box` или `xray`. Ядро, которое запускает протокол.                                                                  |
| `schemes`  | список текстов | Начала ссылок, например `["stormdns"]`.                                                                                   |
| `outbound` | объект         | Конфигурация outbound (или ядра). Используйте заполнители `${key}`, которые заполняются из профиля и из `customSettings`. |

### Пользовательские настройки

Каждый элемент `customSettings` становится элементом управления на странице модуля:

| Поле         | Тип            | Значение                                                 |
| ------------ | -------------- | -------------------------------------------------------- |
| `key`        | текст          | Уникальное имя. Используйте его в заполнителях `${key}`. |
| `title`      | текст          | Подпись.                                                 |
| `type`       | текст          | `text`, `number`, `switch` или `choice`.                 |
| `default`    | любой          | Начальное значение.                                      |
| `min`, `max` | число          | Ограничения для `number`.                                |
| `options`    | список текстов | Варианты для `choice`.                                   |
| `help`       | текст          | Короткое пояснение под элементом.                        |

## Пример: модуль StormDNS

Это полный `module.json` с добавленными полями протокола и настроек. Описание взято из вашего исходного текста о StormDNS.

```json
{
  "apiVersion": 1,
  "name": "StormDNS",
  "version": "1.0.0",
  "description": "DNS-туннель: трафик инкапсулируется в DNS-запросы к открытым рекурсивным резолверам. Полезен там, где открыт только DNS (порт 53). Пропускает только TCP и DNS — UDP/QUIC не туннелируются, поэтому UDP-протоколы (hysteria2/tuic/wireguard) каскадом за ним не работают.",
  "homepage": "https://github.com/masterking32/MasterDnsVPN",
  "updateUrl": "https://github.com/MatenLi/stormdns-module",
  "schemes": ["stormdns"],
  "parallelPing": false,
  "pingWhileConnected": true,
  "handoverMode": "signal",
  "relayWindowSec": 0,
  "pingTimeoutSec": 60,
  "helperBinary": { "android": "libmdvpnhelper.so" },
  "protocols": [
    {
      "id": "stormdns-dns",
      "name": "StormDNS",
      "core": "sing-box",
      "schemes": ["stormdns"],
      "outbound": {
        "type": "socks",
        "server": "127.0.0.1",
        "server_port": "${localPort}",
        "version": "5"
      }
    }
  ],
  "customSettings": [
    {
      "key": "localPort",
      "title": "Локальный порт",
      "type": "number",
      "default": 5353,
      "min": 1024,
      "max": 65535,
      "help": "Порт, на котором слушает помощник."
    },
    {
      "key": "resolvers",
      "title": "Резолверы",
      "type": "text",
      "default": "",
      "help": "DNS-резолверы через запятую. Оставьте пустым, чтобы использовать встроенный список."
    },
    {
      "key": "mode",
      "title": "Режим",
      "type": "choice",
      "default": "fast",
      "options": ["fast", "stable"],
      "help": "Fast быстрее, stable выдерживает плохие сети."
    },
    {
      "key": "compression",
      "title": "Сжатие",
      "type": "switch",
      "default": true
    }
  ]
}
```

Что делает каждая часть этого примера:

- Элемент `protocols` означает, что ссылка, начинающаяся с `stormdns://`, создаёт профиль StormDNS.
- `${localPort}` заменяется значением со страницы модуля, поэтому порт можно менять без правки модуля.
- `helperBinary` называет нативную библиотеку, которая запускает DNS-туннель. Приложение загружает её при подключении профиля.

## Обновление модуля с GitHub

Если задан `updateUrl`, кнопка **Проверить обновление** читает последний релиз этого репозитория. Когда его
`version` выше установленной, модуль показывает **Обновить**. Релиз должен содержать файл `.zip`
в описанном выше формате.

## Правила и ограничения

- Модуль не может менять файлы самого приложения или других модулей.
- Держите `module.json` в корректном JSON. MatenLi показывает строку и столбец первой ошибки.
- `helperBinary` загружается внутри приложения как библиотека. Программы, которые работают отдельными процессами,
  ограничены Android, поэтому модуль не должен зависеть от запуска собственного исполняемого файла.
- Устанавливайте только модули от людей, которым доверяете. Модуль запускает нативный код.
- Как написать модуль, см. на странице [Плагины](/wiki/plugins/).
