В этом руководстве создаётся небольшой плагин с нуля. Понадобятся текстовый редактор, программа для ZIP-архивов
и аккаунт на GitHub, если хотите его опубликовать. Для первой версии программировать не нужно.

## Шаг 1: поймите части

Плагин — это папка, которая становится ZIP-файлом:

```text
my-plugin/
└── module.json
```

`module.json` — текстовый файл, который описывает ваш плагин. Простому плагину больше ничего не нужно.

## Шаг 2: напишите module.json

Создайте текстовым редактором файл `module.json`. Для начала скопируйте это:

```json
{
  "apiVersion": 1,
  "name": "Мой первый плагин",
  "version": "0.1.0",
  "description": "Добавляет настройку для моего сервера."
}
```

Сохраните. Плагин пока ничего не делает, но MatenLi его принимает. Теперь можно проверить импорт.

## Шаг 3: проверьте файл

Вставьте содержимое в любой проверщик JSON, например сайт «JSON validator». Если написано, что JSON корректен,
файл правильный. Частая ошибка — пропущенная запятая или кавычка. Каждой открывающей `"` нужна закрывающая.

## Шаг 4: добавьте настройку

Настройка появляется на странице модуля. Добавьте список `customSettings`:

```json
{
  "apiVersion": 1,
  "name": "Мой первый плагин",
  "version": "0.1.0",
  "description": "Добавляет настройку для моего сервера.",
  "customSettings": [
    {
      "key": "greeting",
      "title": "Приветствие",
      "type": "text",
      "default": "привет",
      "help": "Любой текст."
    }
  ]
}
```

Импортируйте файл снова. На странице модуля появится текстовое поле **Приветствие**.

## Шаг 5: добавьте протокол

Протокол объясняет MatenLi, как построить соединение по ссылке. Это самая аккуратная часть.
Скопируйте пример из [Примеров](/wiki/examples/) и поменяйте только имена и префикс. На странице
[Модули](/wiki/modules/) описаны все поля.

## Шаг 6: заархивируйте

1. Выберите `module.json` и другие файлы.
2. Щёлкните правой кнопкой и выберите **Сжать** (Windows) или **Создать архив** (macOS, Linux).
3. Назовите архив `my-plugin.zip`. Файл должен быть ZIP, а не RAR или 7z.

## Шаг 7: опубликуйте на GitHub

1. Создайте публичный репозиторий, например `my-plugin`.
2. Загрузите `module.json` в репозиторий.
3. Откройте **Releases**, нажмите **Create a new release**, выберите тег, например `v0.1.0`, и прикрепите `my-plugin.zip`.
4. Добавьте в `module.json` строку `"updateUrl": "https://github.com/your-name/my-plugin"`, чтобы работали обновления.

Когда вы повышаете `version` и публикуете новый релиз, приложение предлагает обновление.

## Частые проблемы

| Проблема                 | Решение                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| «Invalid JSON»           | Проверьте запятые, кавычки и скобки. Используйте проверщик JSON.                            |
| «Unsupported apiVersion» | Укажите `"apiVersion": 1`.                                                                  |
| Настройка не появляется  | Проверьте, что `customSettings` находится в основном объекте, а не внутри другого элемента. |
| Обновление не появляется | Тег релиза должен быть выше установленной `version`.                                        |
