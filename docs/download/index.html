Before you install

  • Android 12 or newer, arm64-v8a or armeabi-v7a.
  • Allow installs from this source when Android asks. The app is not on Google Play.
  • Check the SHA-256 of the file against the release notes when they list one.

Build it yourself

Every push builds a debug APK. Open the Build debug APK workflow and download the matenli-debug artifact from the latest run.
