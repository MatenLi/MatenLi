Промпт для ИИ

Готовый промпт, с помощью которого ассистент ИИ напишет плагин MatenLi.

На этой странице
  • Как пользоваться
  • Что делает промпт
  • Советы

Вставьте полный промпт в ассистент ИИ и опишите, какой плагин нужен. Промпт опубликован на английском как обычный файл для ИИ: /wiki/PROMPT.md. Ассистенты понимают английский, поэтому промпт не переводится.

Как пользоваться#

  1. Откройте файл PROMPT.md и скопируйте всё содержимое.
  2. Начните новый чат с ассистентом ИИ и сначала вставьте промпт.
  3. Под промптом опишите, что нужно. Например:

Сделай плагин MatenLi для туннеля StormDNS. Пользователь выбирает локальный порт и список резолверов.

  1. Прочитайте ответ. Сохраните полученный module.json, проверьте его проверщиком JSON и заархивируйте.
  2. Импортируйте ZIP в MatenLi в разделе Модули.

Что делает промпт#

Промпт сообщает ИИ:

  • точный формат модулей (версия 1), включая каждое поле и его тип
  • какие ядра есть и какие поля они ожидают
  • задать один вопрос, если протокол не ясен
  • вернуть только корректный module.json и короткое пояснение

Советы#

  • Дайте ИИ ссылку или документацию протокола, который хотите добавить.
  • Попросите объяснить каждое поле простыми словами, чтобы выучить формат.
  • Всегда проверяйте результат. ИИ может ошибаться, а плагин работает на вашем телефоне.
