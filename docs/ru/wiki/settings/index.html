Справочник настроек

Все настройки MatenLi, что каждая делает и каким значением она задана по умолчанию.

Откройте Настройки из боковой панели. Настройки сгруппированы по разделам. Эта страница перечисляет их в том же порядке.

Статус: Блокировка рекламы и Поиск страны появятся в следующем выпуске. Настройки маршрутов, DNS и входящих показаны здесь как целевая структура.

Настройки приложения#

Настройка По умолчанию Что делает
Автоподключение Выкл Подключается к выбранному профилю при открытии приложения.
Ночной режим Системный Светлый, тёмный или как в системе.
Тема приложения Динамическая Динамические цвета из обоев, один из пяти пресетов или свой цвет (hex, например #7F52CF).
Показывать нижнюю панель Вкл Выключите, чтобы освободить место для списка.
Режим службы VPN VPN — обычный режим. Только прокси запускает локальный прокси без VPN.
Интерфейс TUN Вкл Виртуальное сетевое устройство, которое несёт весь трафик.
MTU 1500 Размер пакета. Уменьшите (например, до 1280), если страницы зависают в некоторых сетях.
Интервал скорости 1 с Как часто обновляются цифры скорости.
Уровень журнала Info Сколько ядро пишет в журнал. Debug — подробно.
Свой конфиг Пусто Ваш JSON sing-box. Он заменяет сгенерированный конфиг. Для опытных.

Настройки маршрутов#

Настройка По умолчанию Что делает
Выход по умолчанию Прокси Через что идёт трафик, который не подошёл ни под одно правило.
Блокировать рекламу Выкл Блокирует список рекламных доменов.
Обходить частные адреса Вкл Локальные адреса остаются напрямую.

Настройки DNS#

Настройка По умолчанию Что делает
Удалённый DNS https://1.1.1.1/dns-query DNS для имён, которые идут через прокси.
Локальный DNS 8.8.8.8 DNS для имён, которые идут напрямую.
Fake IP Вкл См. Маршрутизацию.
Стратегия IPv4 в приоритете Только IPv4, только IPv6 или предпочитать один из них.

Настройки входящих#

Настройка По умолчанию Что делает
Смешанный порт 2080 Локальный порт SOCKS и HTTP.
Разрешить LAN Выкл Позволяет другим устройствам пользоваться локальным прокси.
Имя и пароль Пусто Защищают локальный прокси.

Проверка соединения#

Настройка По умолчанию Что делает
Тестовый URL https://www.gstatic.com/generate_204 Адрес для проверок по URL.
Таймаут пинга 5 с Сколько ждёт проверка.
Пинг при подключении Вкл Держит число задержки актуальным.
Параллельный пинг Выкл Проверяет несколько профилей одновременно. Может перегрузить медленную сеть.

Поиск страны#

Настройка По умолчанию Что делает
Поиск страны Вкл Определяет страну выходного адреса через api.ip2location.io.
Ключ API Пусто Необязательно. Без ключа бесплатный лимит — 1000 запросов в день.

На ip2location.io отправляется только адрес выхода. Выключите эту настройку, если не хотите передавать адрес сторонним серверам.
