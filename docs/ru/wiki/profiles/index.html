Что такое профиль#

Профиль — это один сервер вместе со всем, что нужно для подключения к нему: адрес, порт, протокол, настройки безопасности и имя. Каждый профиль хранится только на вашем телефоне.

Добавление профиля#

Есть пять способов. Нажмите + в правом нижнем углу и выберите:

Способ Когда использовать
Вставить из буфера Вы скопировали ссылку. Это обычный способ.
Сканировать QR-код Провайдер показывает QR-код.
Импорт из файла У вас есть текстовый файл с одной ссылкой в строке.
Добавить вручную Вы знаете данные сервера и хотите ввести их сами.
Добавить подписку У вас есть адрес подписки. См. Группы.

Поддерживаемые типы ссылок#

Начало ссылки Протокол Примечания
vless:// VLESS Работает с Reality и TLS.
vmess:// VMess
trojan:// Trojan
ss:// Shadowsocks
hysteria2:// или hy2:// Hysteria 2 Работает на UDP.
tuic:// TUIC Работает на ядре sing-box.
socks://, http:// SOCKS, HTTP-прокси
{ ... } Сырой JSON sing-box Вставьте полный объект outbound.

Статус: ссылки XHTTP (SplitHTTP) требуют ядро Xray. Это ядро добавляется в следующем выпуске. До тех пор MatenLi показывает сообщение «XHTTP требует ядро Xray» и не подключается.

Редактирование профиля#

Нажмите на профиль и удерживайте его или нажмите кнопку ... на нём, затем выберите Изменить. Редактор показывает все поля для этого протокола. Поля, которые не нужны для протокола, скрыты.

  • Измените имя на такое, которое вы узнаете.
  • Не трогайте дополнительные поля, если провайдер не просил их менять.
  • Нажмите Сохранить. Ошибки появятся под полем, которое их вызвало.

Действия с профилем#

Нажмите кнопку ... на профиле, чтобы открыть его меню:

Действие Что делает
Проверить Измеряет задержку до тестового адреса. Результат появится на карточке.
TCP-пинг Проверяет, что порт сервера отвечает. Быстрее и не требует VPN.
Изменить Открывает редактор.
Дублировать Создаёт копию, полезно для другого порта или маршрута.
Поделиться ссылкой Показывает ссылку и QR-код.
Копировать ссылку Копирует ссылку в буфер обмена.
Переместить в группу Перемещает профиль в другую группу.
Удалить Удаляет профиль. Профиль из подписки вернётся при следующем обновлении подписки.

Пример#

У вас есть ссылка:

vless://0f5c1a2e-1111-4444-9999-abcdef012345@example.org:443?security=tls&type=ws&path=%2Fchat&sni=example.org#My%20home%20server

Её вставка создаст профиль с именем My home server. Сервер — example.org, порт 443, TLS и WebSocket. Нажмите Проверить, чтобы измерить задержку.

Советы#

  • Держите один профиль на один сервер. Дублируйте его, когда нужен вариант.
  • Называйте профили по месту и провайдеру, например Хельсинки, провайдер А. Имена пишутся свободно.
  • Не делитесь ссылками, которых вы сами не создавали. Ссылка содержит пароль к серверу.
