Updating and backup

Back up everything before you uninstall or update, then load the backup in the new version.

On this page
  • Before you update or uninstall
  • After you install the new version
  • If you forgot to back up
  • Summary

Important: before you uninstall MatenLi or install a new version over it, make a backup. Uninstalling deletes all profiles, groups, subscriptions, routes, modules and settings on your phone.

Before you update or uninstall#

  1. Open Settings and tap Create backup.
  2. Choose where to save the file. Save it somewhere outside the app, for example your Downloads folder or cloud storage.
  3. Check that the file is there and that its size is not zero.
  4. Only then uninstall the app or install the new version.

A backup file contains your profiles, groups, subscriptions, routes, modules and settings. Keep it private: it contains the passwords and links to your servers.

After you install the new version#

  1. Open MatenLi. The first-launch notice reminds you to load your backup.
  2. Open Settings and tap Load backup.
  3. Choose the backup file you saved.
  4. Check the profiles and groups. Tap Test all to confirm that the servers still answer.

Note: if a new version changes the backup format, MatenLi tells you which parts it could not load and keeps the rest. Nothing is overwritten until you confirm.

If you forgot to back up#

Your profiles and subscriptions are gone after an uninstall. Ask your provider for the links again, or use the subscription address: adding it again restores every server in the group.

Summary#

Step When Action
Back up Before uninstall or update Settings > Create backup
Install Then Install the new APK
