Плагины

Что такое плагин, где его взять и как написать.

Плагины — это дополнения, которые MatenLi загружает как модули. Эта страница — обзор. Для действий используйте другие страницы:

  • Написать свой плагин: пошаговое руководство, которое не требует опыта программирования.
  • Примеры: готовые полные файлы модулей для копирования.
  • Промпт для ИИ: промпт, который заставит ассистента ИИ написать плагин за вас.

Что может добавить плагин#

Вид Пример
Протокол Новый тип ссылки, например stormdns://.
Настройка ядра Переключатель или выбор, который меняет сгенерированный конфиг.
Проверка Своя проверка задержки для протокола.
Помощник Нативная библиотека, которая нужна протоколу для работы.

Установка плагина#

  1. Скачайте файл .zip плагина.
  2. Откройте Модули в боковой панели и нажмите Импорт (zip).
  3. Выберите файл. Плагин появится в списке.
  4. Откройте его, чтобы изменить настройки, закрепить или выключить.

Где искать плагины#

  • В организации MatenLi на GitHub перечислены официальные плагины.
  • Можно использовать любой репозиторий GitHub, который публикует релиз с .zip в формате модулей.
  • Прежде чем установить плагин от незнакомого человека, спросите в Telegram-группе.

Доверие#

Плагин запускает код на вашем телефоне. Устанавливайте только плагины, исходный код которых вы можете прочитать, из релизов, которым доверяете. Проверьте updateUrl, прежде чем включать автоматическую проверку обновлений.

Как написать свой#

Начните с Написать свой плагин. Большинство плагинов — это просто файл module.json. Нативная библиотека нужна, только если протоколу требуется код, который нельзя описать в JSON.
