Маршрутизация, DNS и входящие

Что идёт через сервер, как разрешаются имена и как к приложению подключаются локальные программы.

Маршрутизация#

Маршрут — это правило. Для каждого соединения MatenLi проверяет правила сверху вниз. Первое подходящее правило решает, что будет с трафиком.

У каждого правила три части:

Часть Пример Значение
Тип совпадения Домен, IP, порт, приложение Что проверяет правило.
Значение *.example.org Текст или диапазон для сравнения.
Выход Прокси, Напрямую, Блок Куда идёт подходящий трафик.

Примеры#

Цель Тип совпадения Значение Выход
Банковское приложение обходит VPN Домен bank.example.com Напрямую
Домашняя сеть остаётся локальной IP 192.168.0.0/16 Напрямую
Блокировать трекер Домен tracker.example.net Блок
Всё видео через сервер Порт 1935 Прокси

Частные адреса (10.x, 192.168.x, 127.x) всегда идут напрямую, чтобы локальные устройства работали.

DNS#

DNS превращает имя, например example.org, в адрес. У MatenLi три DNS-сервера:

Сервер Для чего
Удалённый Имена, которые идут через прокси. Разрешаются на стороне сервера.
Локальный Имена, которые идут напрямую, например ваш домашний роутер.
Fake IP Позволяет MatenLi видеть, какое имя запросило приложение, даже для трафика только по IP. Выключите, если приложения ломаются.

Настройки каждого сервера — в Настройках.

Входящий прокси (inbound)#

MatenLi может открыть локальный прокси на вашем телефоне. Тогда другие приложения или другое устройство в вашей Wi-Fi-сети смогут использовать MatenLi как SOCKS- или HTTP-прокси.

Настройка По умолчанию Примечания
Смешанный порт 2080 SOCKS и HTTP на одном порту.
Разрешить LAN Выкл Включайте только в доверенной сети.
Авторизация Нет Добавьте имя пользователя и пароль, прежде чем разрешать доступ из LAN.

Внимание: открытый прокси в публичной сети позволяет посторонним пользоваться вашим сервером. Держите авторизацию включённой.

Приложения (VPN для отдельных приложений)#

По умолчанию весь трафик идёт через VPN. Настройка Приложения позволяет выбрать:

  • Все приложения через прокси: по умолчанию.
  • Только выбранные приложения: через VPN идут только отмеченные приложения.
  • Обходить выбранные приложения: через VPN идут все, кроме отмеченных.

Выбирайте приложения из списка. Ищите по названию, если список длинный.

Статус: выбор приложений заменяет прежний переключатель. Он появится в следующем выпуске.
